# Agnes Image 2.1 Flash 多图合成完整经验总结

> 测试日期：2026-08-13
> 测试版本：v10-v18 共9轮测试
> 最终方案：v15两步法 + v17角度对齐 + v18最简侧身写法

---

## 一、最终方案流程

```
Step 1: 文生图 → 角色单独视图（1K / 1:1 / 纯白底）
Step 2: 2图合成 → 双人图（1K / 角度匹配目标分镜）
Step 3: 文生图 → 场景图（1K / 9:16 / 视角匹配双人图）
Step 4: 2图合成 → 分镜图（双人图+场景图 / 1K / 9:16）
```

### 关键原则
**双人图姿态角度 = 场景图视角角度 = 分镜图角色角度**

---

## 二、各步骤 Prompt 模板

### Step 1: 角色单独视图

```
[角色描述]，正面全身照，面向镜头站立。
[面部特征]，[服装描述]。
纯白色背景，绝对纯净的白色背景，无任何多余元素，无家具无道具无阴影无渐变无纹理，只有人物和纯白背景，棚拍风格，均匀柔光照明，高细节，写实摄影风格。
```

参数：`1K` / `1:1`

### Step 2: 双人图（按分镜角度选择）

**侧身对峙分镜 → 侧身双人图（最简写法）**：
```
将第一张图作为角色A，第二张图作为角色B，生成一张两个角色侧面站立的全身照，角色A面向右侧角色B面向左侧，两人侧身面对面，保留两个角色的面部特征、身份和服装穿着，纯白色背景无任何多余元素，使用均匀柔光照明和写实摄影风格。
```

**走开分镜 → 背影双人图**：
```
将第一张图作为角色A，第二张图作为角色B，生成一张两个角色背对镜头的全身照，角色A在前方大步走，角色B在后方伸手想要叫住，保留两个角色的服装穿着和发型，纯白色背景无任何多余元素，使用均匀柔光照明和写实摄影风格。
```

**正面分镜 → 正面双人图**：
```
将第一张图作为角色A，第二张图作为角色B，生成一张两个角色并排站立的全身照，保留两个角色的面部特征、身份和服装穿着，纯白色背景无任何多余元素，使用均匀柔光照明和写实摄影风格。
```

参数：`1K` / `9:16`（或 `1:1`）

### Step 3: 场景图

```
[场景描述]，无人，电影级构图，高细节写实摄影风格。
```

参数：`1K` / `9:16`

**要求**：场景中不能有人物，视角需与双人图角度匹配

### Step 4: 分镜图

```
将第一张图作为角色参考，第二张图作为场景参考，生成一张[动作描述]的画面，保留角色的面部特征和服装穿着，使用[光照风格]和电影级写实构图。
```

参数：`1K` / `9:16`

## 三、核心经验（按重要程度排序）

### 经验1：角度对齐是关键（v17发现）

**问题**：正面双人图 + 侧身场景图 → 模型强行转角度 → 动作变形

**解决**：双人图姿态角度必须和场景图视角对齐
- 对峙分镜 → 侧身双人图 + 走廊纵深场景
- 走开分镜 → 背影双人图 + 走廊纵深场景
- 正面分镜 → 正面双人图 + 正面场景

**验证**：v17组3用背影双人图完美实现了"转身走开"（v16用正面双人图完全失败）

### 经验2：两步法优于直接3图合成（v15发现）

**问题**：3图合成（角色A+角色B+场景）模型注意力分散

**解决**：拆成两步2图合成
- Step2: 角色A+角色B → 双人图
- Step4: 双人图+场景图 → 分镜图

每步只用2张图，符合官方提示词结构，合成质量更稳定

### 经验3：1K足够，无需4K（v13/v14发现）

**问题**：4K分辨率耗时80-120秒，效率低

**解决**：1K分辨率9-17秒完成，质量满足需求

**对比**：4K和1K在面部一致性上无显著差异

### 经验4：纯白背景必须强化（v16发现）

**问题**：普通"纯白背景"描述模型会添加阴影/渐变

**解决**：prompt中强调"绝对纯净的白色背景，无任何多余元素，无家具无道具无阴影无渐变无纹理，只有人物和纯白背景"

### 经验5：简单动作效果好，复杂动作需拆解（v16发现）

| 动作类型 | 效果 | 说明 |
|:---|:---|:---|
| 双人站立对峙（叉腰/指人/怒视） | ✅ 好 | 简单明确 |
| 单人+逆光（微笑/走动） | ⚠️ 部分偏差 | 角色位置可能偏移 |
| 转身/走开 | ❌ 直接写失败 → ✅ 用背影双人图解决 | 需角度对齐 |
| 坐姿+复杂动作（甩文件） | ❌ 差 | 面部易失真，避免使用 |
| 推门 | ⚠️ 推门者可能变成男性 | 需在prompt中明确主语 |

### 经验6：官方Prompt结构就够用（v10发现）

**问题**：加人物五官描述（瓜子脸/杏眼/鼻梁自然）反而干扰模型

**解决**：用官方结构 `将第N张图作为...，生成...，保留...，使用...`

**对比**：极简prompt效果最好，加约束反而更差

### 经验7：侧身写法用最简单的（v18发现）

**问题**：3/4角度模型无法准确执行

**解决**：用"侧面站立"最简写法即可，5种写法全部成功

**最佳写法**：`两个角色侧面站立，角色A面向右侧角色B面向左侧，两人侧身面对面`

### 经验8：负面词有副作用（v10发现）

**问题**：负面词（西化面孔/高鼻深目）导致面部过度平滑、表情僵硬

**解决**：不使用负面词

### 经验9：场景图必须无人（v16发现）

**问题**：场景图中有人物会导致合成时出现多余角色

**解决**：场景图prompt中加"无人"

### 经验10：参考图类型选择（v10-v14验证）

| 参考图类型 | 面部一致性 | 服装一致性 | 适用场景 |
|:---|:---|:---|:---|
| 面部特写 | ✅ 最好 | ❌ 全跑偏 | 不推荐（丢了服装） |
| 三视图/四视图 | ❌ 西化 | ✅ 满分 | 不推荐（面部占比太小） |
| 4K全身照 | ⚠️ 轻度西化 | ✅ 满分 | 不推荐（耗时且仍西化） |
| **1K纯白底正面照** | **✅ 达标** | **✅ 满分** | **推荐使用** |

## 四、问题与解决方案汇总

| 问题 | 出现版本 | 解决版本 | 解决方案 |
|:---|:---|:---|:---|
| 女性面部西化 | v11-v14 | v15 | 两步法+纯白底1K正面照 |
| 服装跑偏 | v10 | v11+ | 全身参考图（正面照/四视图） |
| 动作变形（转身走开） | v16-H4 | v17-I3 | 背影双人图（角度对齐） |
| 复杂动作失真（甩文件） | v16-H2 | 待解决 | 避免坐姿+复杂动作组合 |
| 推门者错误 | v16-H5 | 待解决 | prompt中明确动作主语 |
| 3/4角度无法执行 | v17-I2 | v18 | 用"侧面站立"最简写法 |
| 背景不纯白 | v15 | v16 | 强化纯白描述 |
| 负面词副作用 | v10-A3 | v10-A1 | 不使用负面词 |

## 五、待解决问题

1. **坐姿场景**：坐姿+复杂动作（如甩文件）面部易失真，需进一步测试
2. **推门动作**：动作主语可能偏移，需在prompt中更明确
3. **3/4角度**：模型对精确角度控制能力有限，需找到更合适的描述方式
4. **多角色场景**：3个以上角色同框未测试

## 六、API 参数标准

```python
# 文生图（Step1/Step3）
{
    "model": "agnes-image-2.1-flash",
    "prompt": prompt,
    "size": "1K",
    "ratio": "1:1",  # 角色图用1:1，场景图用9:16
    "extra_body": {}
}

# 图生图（Step2/Step4）
{
    "model": "agnes-image-2.1-flash",
    "prompt": prompt,
    "size": "1K",
    "ratio": "9:16",
    "extra_body": {
        "image": [image1_base64, image2_base64],
        "response_format": "url"
    }
}
```
