## 二、角色设定

- **气质**：威严但有中年油腻感
- **情绪弧**：自以为掌控 → 被反驳 → 恼羞成怒 → 无话可说

### 配角 — 李姐（可选）

## 五、技术栈与工具

### 核心 AI 服务
- **图像生成**：Agnes Image 2.1 Flash（`agnes-image-2.1-flash`）
- **视频生成**：Agnes Video v2.0（ti2vid/keyframes 模式）
- **API 接入**：通过 MCP 工具调用 Agnes 平台 API

### 辅助工具
- **视频拼接**：ffmpeg（concat 多个镜头）
- **HTML 报告**：自研脚本生成，使用 base64 内嵌媒体
- **记忆系统**：MCP memos-mcp（search_memory / add_message）

### API 调用参数标准

```python
# 文生图（Step1 角色单独视图 / Step3 场景图）
payload = {
    "model": "agnes-image-2.1-flash",
    "prompt": prompt,
    "size": "1K",       # 角色图用1K，场景图可用4K
    "ratio": "1:1",     # 角色图1:1，场景图9:16
    "extra_body": {}
}

# 图生图（Step2 双人合成 / Step4 分镜合成）
payload = {
    "model": "agnes-image-2.1-flash",
    "prompt": prompt,
    "size": "1K",
    "ratio": "9:16",
    "extra_body": {
        "image": [image1_base64, image2_base64],
        "response_format": "url"
    }
}
```

## 六、推荐工作流程（两步法）

这是经过 v10-v21 共 12 轮测试验证后的最优方案：

```
Step 1: 文生图 → 角色单独视图（1K / 1:1 / 纯白底）
          ├── 苏晓单独视图
          └── 张经理单独视图
                ↓
Step 2: 2图合成 → 双人图（1K / 角度匹配目标分镜）
          输入：苏晓单独视图 + 张经理单独视图
          输出：两人 together 的全身照（侧身/背影/正面取决于分镜）
                ↓
Step 3: 文生图 → 场景图（1K / 9:16 / 视角匹配双人图）
          注意：场景中必须包含分镜动作所需的所有道具！
                ↓
Step 4: 2图合成 → 分镜图（双人图+场景图 / 1K / 9:16）
                ↓
Step 5: Keyframes 视频生成（首帧+尾帧 → mp4）
                ↓
Step 6: ffmpeg 拼接所有镜头 → 完整版短片
```

### 关键原则
1. **双人图姿态角度 = 场景图视角角度 = 分镜图角色角度**（角度必须对齐）
2. **两步法优于直接3图合成**（每步只用2张图，模型注意力更集中）
3. **1K分辨率足够**（4K耗时80-120秒，1K仅9-17秒，质量无显著差异）
4. **场景图必须包含所有道具**（不能在分镜prompt中凭空创造物体）
5. **首尾帧道具状态变化通过不同场景参考图实现**（场景参考图 > prompt文字）
