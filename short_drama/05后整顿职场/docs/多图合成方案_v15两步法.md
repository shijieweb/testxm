# Agnes Image 2.1 Flash 多图合成方案 — v15 两步法

> 经 v10-v15 六轮测试验证，v15 两步法是最终采用方案。
> 测试日期：2026-08-13

---

## 一、方案概述

采用**两步法 + 官方2图提示词**，通过递进式2图合成实现双角色场景分镜图生成。

核心思路：不直接用3图合成（角色A+角色B+场景），而是拆成两步——先把两个角色合成到一张图里，再用这张双人图和场景图合成最终分镜。每一步都只用2张图，符合官方提示词结构。

---

## 二、完整流程

```
Step 1: 生成角色单独视图（文生图）
  ├── 苏晓单独视图（1K / 1:1）
  └── 张经理单独视图（1K / 1:1）
        ↓
Step 2: 2图合成 → 双人图（图生图）
  ├── 输入：苏晓单独视图 + 张经理单独视图
  ├── 输出：两人在一起的全身照（1K / 9:16）
  └── Prompt：官方2图结构
        ↓
Step 3: 2图合成 → 分镜图（图生图）
  ├── 输入：双人图 + 场景图
  ├── 输出：角色在场景中的分镜画面（1K / 9:16）
  └── Prompt：官方2图结构
```

---

## 三、各步骤详细规格

### Step 1：生成角色单独视图

**方式**：文生图（无参考图输入）

**参数**：
| 参数 | 值 |
|:---|:---|
| 模型 | agnes-image-2.1-flash |
| 尺寸 | 1K |
| 比例 | 1:1 |
| 背景要求 | 纯白色背景 |

**苏晓 Prompt**：
```
年轻东亚女性，22岁，正面全身照，面向镜头站立。
浅棕色长直发及腰中分有空气刘海，瓜子脸，杏眼双眼皮，鼻梁自然高度，
身穿浅米色翻领长袖衬衫，深灰色高腰及膝铅笔裙，白色休闲运动鞋，
佩戴细链锁骨项链和小巧耳钉，
纯白色背景，棚拍风格，均匀柔光照明，高细节，写实摄影风格。
```

**张经理 Prompt**：
```
中年东亚男性，45岁，正面全身照，面向镜头站立。
圆脸微胖，黑色短发发际线略后移，戴黑框眼镜，面部有法令纹，
身穿深蓝色短袖衬衫，黑色西裤，黑色皮鞋，黑色皮带，
纯白色背景，棚拍风格，均匀柔光照明，高细节，写实摄影风格。
```

**输出**：
- `苏晓_单独视图_1K.jpg`（1024×1024px）
- `张经理_单独视图_1K.jpg`（1024×1024px）

**质检标准**：
- 面部特征匹配（脸型/眼型/发型/鼻梁）
- 服装三件套颜色款式匹配
- 纯白背景无杂物
- 不西化、不变形

---

### Step 2：2图合成 → 双人图

**方式**：图生图（2张参考图）

**输入图**：[角色A单独视图, 角色B单独视图]

**参数**：
| 参数 | 值 |
|:---|:---|
| 模型 | agnes-image-2.1-flash |
| 尺寸 | 1K |
| 比例 | 9:16 |
| 图片数 | 2 |

**Prompt**（官方2图结构）：
```
将第一张图作为角色A，第二张图作为角色B，生成一张两个角色站在走廊中面对面的全身照，保留两个角色的面部特征、身份和服装穿着，使用自然室内光照和电影级写实构图。
```

**Prompt 结构拆解**：
```
将第一张图作为[角色定位A]，
第二张图作为[角色定位B]，
生成[目标画面描述]，
保留[保留要求]，
使用[风格/光照/构图]。
```

**输出**：`v15_Step2_双人合成图.jpg`（1K / 9:16）

**质检标准**：
- 双角色面部特征与Step1一致
- 双角色服装与Step1一致
- 两人空间关系正确（面对面/站位）
- 无第三人干扰

---

### Step 3：2图合成 → 分镜图

**方式**：图生图（2张参考图）

**输入图**：[双人图, 场景图]

**参数**：
| 参数 | 值 |
|:---|:---|
| 模型 | agnes-image-2.1-flash |
| 尺寸 | 1K |
| 比例 | 9:16 |
| 图片数 | 2 |

**Prompt**（官方2图结构）：
```
将第一张图作为角色参考，第二张图作为场景参考，生成一张角色在场景中角色B伸手拦住角色A去路的画面，保留角色的面部特征和服装穿着，使用自然室内光照和电影级写实构图。
```

**输出**：`v15_Step3_分镜图.jpg`（1K / 9:16）

**质检标准**：
- 双角色面部特征一致
- 双角色服装一致
- 场景与场景图一致
- 动作符合剧情描述（B拦住A）
- 无多余角色

---

## 四、场景图生成

**方式**：文生图（无参考图输入）

**参数**：
| 参数 | 值 |
|:---|:---|
| 模型 | agnes-image-2.1-flash |
| 尺寸 | 4K（场景图用高分辨率，提升细节） |
| 比例 | 9:16 |

**场景 Prompt 示例**：
```
现代办公走廊，两侧玻璃隔断办公室，浅灰色地毯地面，
天花板长条形LED照明灯，远处有绿色紧急出口标志，无人，
逆光效果，电影级构图，高细节写实摄影风格。
```

**要求**：
- 场景中**无人**（避免人物干扰）
- 与剧情场景匹配
- 可复用于同一场景的多个分镜

---

## 五、质检维度（5项）

| 序号 | 质检项 | 检查内容 | 适用步骤 |
|:---|:---|:---|:---|
| 1 | 面部一致性 | 脸型/眼型/发型/鼻梁/不西化/不变形 | Step 1-3 全检 |
| 2 | 服装一致性 | 上衣颜色款式 + 下装颜色款式 + 鞋子颜色款式 | Step 1-3 全检 |
| 3 | 角色识别 | 双角色性别/年龄/身份可区分 | Step 2-3 |
| 4 | 场景一致性 | 场景与场景图匹配 | Step 3 |
| 5 | 动作准确性 | 动作与剧情描述一致 | Step 2-3 |

---

## 六、关键经验

1. **2图优于3图**：每步只用2张图，模型注意力集中，合成质量更稳定
2. **1K足够**：1K分辨率速度快（9-17秒），质量满足需求，无需4K
3. **官方Prompt结构**：`将第N张图作为...，生成...，保留...，使用...` 足够，不需要加人物五官描述
4. **纯白背景**：角色单独视图必须用纯白背景，排除环境干扰
5. **场景图无人**：场景图中不能有人物，避免合成时出现多余角色
6. **递进合成**：先角色融合 → 再场景融合，比一步到位更可控

---

## 七、适用场景

| 场景 | 参考图组合 | 说明 |
|:---|:---|:---|
| 单角色分镜 | 角色单独视图 + 场景图 | 直接Step 3 |
| 双角色分镜 | Step2双人图 + 场景图 | 完整三步流程 |
| 同场景多分镜 | 同一场景图复用 | 场景图生成一次，多分镜复用 |
| 新场景分镜 | 双人图 + 新场景图 | Step2双人图可复用，只需换场景图 |

## 九、API 调用参数汇总

```python
# 文生图（Step1 / 场景图）
payload = {
    "model": "agnes-image-2.1-flash",
    "prompt": prompt,
    "size": "1K",        # 角色图用1K，场景图可用4K
    "ratio": "1:1",      # 角色图1:1，场景图9:16
    "extra_body": {}
}

# 图生图（Step2 / Step3）
payload = {
    "model": "agnes-image-2.1-flash",
    "prompt": prompt,
    "size": "1K",
    "ratio": "9:16",
    "extra_body": {
        "image": [image1_base64, image2_base64],
        "response_format": "url"
    }
}
```
