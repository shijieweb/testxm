## 一、工作背景

2026年7月30日，用户决定制作一部名为《05后整顿职场：绝不加班》的竖屏微短剧。项目采用 Agnes AI 的图像生成（agnes-image-2.1-flash）和视频生成（agnes-video-v2.0）API，通过多图合成 + Keyframes 分镜的方式完成短剧制作。

经过 **21轮测试（v1-v21）** 和 **4轮视频生成测试（v7-v10）**，逐步摸索出一套稳定的工作流和25条经验教训。

## 二、工作总结

### 阶段一：项目启动与初步探索（2026-08-01）
- 生成完整小说（3集）和拍摄分镜（24个镜头）
- 定义5个角色圣经 + 3个场景圣经
- 建立 Agnes 制作规范（生产流水线、角色一致性策略、质检清单）
- 产出：`wuhou-zhengdun-zhichang.html`（83KB，1267行）

### 阶段二：多角度参考图测试（2026-08-13，v1-v14）
- v1-v4：基础多图合成测试（1-4张参考图组合）
- v5-v6：纯白背景效果测试（基础/极简/单角色/面部约束）
- v7：面部特写+场景 2K 强约束方案（生成S01-S08全部8个分镜图）
- v8：自定义英文Prompt视频生成（按官方规则自写，非照搬）
- v9-v14：参考图类型对比测试（四视图/侧身/正面/4K vs 1K）
- 核心发现：面部特写服装丢失、四视图面部西化、3图合成不如2图两步法

### 阶段三：两步法定型与角度对齐（2026-08-13，v15-v19）
- v15：确定两步法基础方案（先合成双人图，再合成分镜图）
- v16：纯白底角色单独视图 + 5组动作测试
- v17：角度对齐关键发现——背影双人图完美实现走开动作
- v18：最简侧身写法验证（5种写法全部成功）
- v19：侧身双人图 + 走廊场景完整分镜测试
- 核心发现：角度必须对齐、两步法稳定、1K足够

### 阶段四：道具管理与动作力度（2026-08-13，v20）
- v20-L1/L2：场景图含桌子后，模型不再凭空生成桌子
- v20-L3：走开背影双人图间距改善
- 核心发现：道具必须在场景图中提前存在，不能靠prompt文字创造

### 阶段五：首尾帧动作分解（2026-08-13，v21）
- v21-M1：标准物理动作版（效果导向尾帧）
- v21-M2：效果导向版（冲击力远强于M1）
- 核心发现：
  - 效果导向 > 执行细节导向（经验#018验证）
  - 首帧"蓄势"概念有偏差（经验#019）
  - 道具状态变化需通过场景图而非prompt控制（经验#020）
  - 角度控制力有限（经验#021）
  - 空间位置描述有偏差（经验#022）

### 阶段六：视频Prompt优化（2026-08-14，v7-v10）
- v7：照搬官方curl原话
- v8：按官方7条规则自写英文prompt
- v9：用中文按相同规则重写
- v10：明确区分"运动元素"和"稳定元素"
- 核心发现：理解规则比照搬重要、中英文效果需对比评估

## 三、核心技术成果

### 3.1 最终工作流（两步法 + 首尾帧）

```
Step 1: 文生图 → 角色单独视图（1K/1:1/纯白底）
Step 2: 2图合成 → 双人图（1K/角度匹配分镜）
Step 3: 文生图 → 场景图（1K/9:16/含道具/视角匹配）
Step 4: 2图合成 → 分镜图（双人图+场景图）
Step 5: Keyframes 视频生成（首帧+尾帧）
Step 6: ffmpeg 拼接
```

### 3.2 25条经验教训
- 15条已验证 ✅
- 8条待验证 ⏳
- 详见：`docs/经验积累库.md`

### 3.3 视频Prompt 7条规则
1. 只描述过渡方式
2. 维持一致性
3. 自然运动
4. 不描述具体动作步骤
5. 不加节奏词
6. 不加运镜指令
7. 不加物理细节

### 3.4 运动/稳定元素分离（v10）
- 运动元素：文件夹移动、纸张飘动
- 稳定元素：角色面部、服装、发型、场景布局
- 结构：`运动元素：XXX；稳定元素：XXX`
