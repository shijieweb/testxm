V2 规划
🔍 向量检索升级
从 V1 的 200 字符关键词匹配升级为语义向量检索，支持深层内容检索和多标签扩展匹配，解决 V1 命中率低的核心痛点。
⚡ 自动触发经验提交
任务完成后自动检测关键节点（里程碑、问题修复、决策变更），自动生成结构化报告并提交，减少人工干预。
🔐 权限控制
multi-agent 场景下实现角色隔离与权限分级，不同角色只能访问其授权的知识范围和角色数据。
📊 自动迁移 pipeline
reports/ → experience.md 的迁移流程自动化，基于价值评分模型自动判定是否迁移，减少人工审核负担。
🏷️ YAML metadata 扩展
在 knowledge 条目 YAML front matter 中增加 keywords 字段，V1 搜索同时匹配 keywords，提升召回率作为 V2 过渡方案。
🔄 并发安全增强
现有 threading.Lock 保护 audit-log 和 reports 写入，V2 扩展至所有共享资源，增加 WAL 机制防止数据丢失。
