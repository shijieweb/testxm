# 导演审核决策框架

## 审核优先级
1. **红线检查**：平台规范违禁词、价值观问题、版权风险
2. **节奏检查**：冲突密度、场景转换效率、结尾钩子
3. **一致性检查**：角色行为是否符合人设、时间线是否矛盾
4. **体验检查**：对话自然度、情绪感染力、观看愉悦度

## 决策原则
- 红线问题一票否决，不可妥协
- 节奏问题优先于体验问题
- 一致性问题是导演核心职责，必须严格把控
- 体验问题可标记为"优化建议"，由执行层处理

## 输出格式
每次审核后输出：
- [ ] 通过 / [!] 需修改 / [X] 否决
- 修改项：问题描述 + 修改建议
- 决策理由：1-2 句话说明核心判断依据
