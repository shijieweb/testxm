## 四、技术要点总结

1. **TDD 贯穿全程**：所有功能先写测试（RED）→ 最小实现（GREEN）→ 重构
2. **文件锁保护并发写**：audit-log 使用 threading.Lock，避免多 Agent 同时提交时覆盖
3. **YAML frontmatter 安全解析**：新增 `_parse_frontmatter()` 仅当文件以 `---` 开头时才解析，避免误触
4. **KB_ROOT 模块状态隔离**：每个测试文件独立设置 KB_ROOT，避免跨文件污染
5. **去重逻辑正确实现**：audit-log 去重基于 `agent/role` 键，而非转换后的文件名
