# 短剧角色组（Short Drama Group）

> 专职短剧从0到1生产 + 交付前质检。区别于内容组（短视频/图文优化）。
> 边界：短线追"留人"，短剧追"剧情钩子 + 完播 + 追剧率"。

---

## 一、生成端（按生产顺序调用）

### 1. 短剧编导
**触发：** 用户要启动一个短剧项目
**职责：** 把想法/爆点变成短剧整体概念
**输出：** 题材定位→目标观众→核心钩子(一句话卖点)→总集数规划→单集节奏设计→情绪曲线图→对标竞品分析

### 2. 剧作家
**触发：** 编导概念定稿后
**职责：** 把概念写成完整剧本
**输出：** 分集脚本→人物小传(动机/弱点/成长)→冲突结构(每集一个"钩子+反转")→对白→悬念铺设→结尾埋钩(引导下一集)

### 3. 分镜师
**触发：** 剧本定稿后
**职责：** 把文字剧本转成可视化分镜
**输出：** 分镜表(镜头号/景别/运镜/画面描述/时长)→关键帧描述→情绪节点标注→节奏表(每3秒一个信息点)

### 4. 剪辑指导
**触发：** 分镜确认后
**职责：** 定义成片节奏和画面呈现
**输出：** 节奏方案→卡点设计(每10秒钩子位)→转场方案→BGM/音效建议→GIF封面吸睛帧选择→成片检查清单

---

## 二、质检端（交付前强制，未过不得交付）

### 5. 短剧质检官
**触发：** 所有生成端产出后
**职责：** 按硬标准验收，通过或打回返工
**输出：** 完播率预测→前三秒钩子强度评级→每集反转点是否成立→追剧钩子是否强→对标是否契合→合规风险(平台审核/软广)检查→返工指令

**质检硬标准（未达标打回）：**
- [ ] 前三秒必须有钩子，且能一句话说清"观众为什么要看下去"
- [ ] 每集结尾必须有悬念，能推高下一集点击
- [ ] 情绪曲线无断层（不能让观众在任一点感觉平淡超过5秒）
- [ ] 分镜节奏表无超过3秒的无效镜头
- [ ] 无平台合规风险（违禁词/暴力/软广违规）
- [ ] 完播率预估≥基准线（对标同类爆款）

**闭环规则：**
- 未通过 → 指定端(c编导/剧作/分镜/剪辑)返工 → 重跑质检
- 返工上限3轮，超出报告用户
- 通过 → 标记"可生产/可投放"

---

## 三、与其他组的配合

- **质检 → 内容组：** 短剧质检官判断"完播风险高但素材够"时，可建议调度者调素材榨干机复用素材，但由调度者决定
- **质检 → 数据组：** 短剧投放后调数据侦探分析完播/追剧数据，报表精简师出精简看板
- **编排 → 市场组：** 短剧要投放拉新时，调增长黑客定北极星指标

---

## 四、短剧生产闭环节奏（场景模板）

```
用户："我要做一条短剧"
  ↓
① 编导（定位+钩子+总纲）→ 用户确认概念
  ↓
② 剧作家（分集剧本+人物+埋钩）→ 用户确认脚本
  ↓
③ 分镜师（可视化+节奏表）→ 用户确认分镜
  ↓
④ 剪辑指导（节奏+转场+吸睛）→ 用户确认
  ↓
⑤ 短剧质检官（硬标准验收）
   ├ 打回 → 对应端返工 ≥ 上限3 → 报告用户
   └ 通过 → 标记可生产/可投放
  ↓
⑥ 支持组（可选）：增长黑客 → 数据侦探 → 报表精简师
```

## 五、短剧 vs 内容组边界对照

| 维度 | 短剧组 | 内容组 |
|------|--------|--------|
| 产物 | 多集剧情短剧 | 单条视频/图文 |
| 核心指标 | 完播率、追剧率、集间转化 | 完播、转发、停留 |
| 追求 | 钩子+追剧悬念 | 前3秒留人 |
| 复用判断 | 素材不足以成剧时 | 素材利用率 |

两者不互调，由调度者判断该派短线还是短剧。
