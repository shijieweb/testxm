## 审查规则

1. 每次标准细化后，军师计算通过率变化（细化前后各跑一遍已有提案，对比通过率）
2. 通过率变化超过±15% → 自动触发秘书审查，不等季度抽查
3. 秘书季度抽查时审查所有变更记录，发现标准被放宽有权回滚
4. 回滚操作也记录到此文件，标注"回滚"及回滚原因

### 5项硬标准（v1.0）
1. **发现真实问题**：该角度能否在已知案例中发现真实问题？（不能→打回）
2. **触发场景清晰**：触发场景是否清晰无歧义，秘书能判断什么时候该用？（模糊→打回）
3. **非重复**：与现有角度的核心问题重叠>2个字段（核心问题+触发场景+使用示例中2个以上相同）→合并而非新增
4. **对立假设验证**：必须回答"如果这个角度是错的，它会掩盖什么问题"。答"不可能错"→打回
5. **可证伪条件验证**：必须写出"如果出现X情况说明这个角度无效"，且X是可观测的。模糊或无法验证→打回
