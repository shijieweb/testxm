## 快速开始

```bash
cd ai-platform
npm install
npm run dev        # 启动开发服务器 http://localhost:5173
npm test           # 运行 66 个测试用例
npm run build      # 生产构建
```

## 项目一句话简介

**AI 驱动需求管理平台**：用户配置一个 AI 模型后，即可用自然语言创建项目、AI 自动优化项目描述、展示默认架构目录并初始化项目结构，实现"AI 主导、开箱即用、最小化落地"的需求管理与研发协作。
